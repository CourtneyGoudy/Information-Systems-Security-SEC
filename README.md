# Information Systems Security (SEC) — Cybersecurity & Defense Labs

This repository is my **Information Systems Security (SEC)** coursework archive for hands-on cybersecurity labs, risk assessments, and defensive security exercises completed at **DeVry University** (*Associate of Applied Science in Cybersecurity and Networking, advancing into a Bachelor's degree*).

---

### What Goes Inside This Repository
Each folder inside this repository represents an **Information Systems Security (SEC)** course (such as *Fundamentals of Information Systems Security*, *Fundamentals of Infrastructure Security*, and *Cybersecurity and Data Privacy*) and contains:
- Lab objectives and security scenarios
- Access control, encryption, network defense, and threat-analysis exercises
- Step-by-step security documentation and key takeaways

---

### Core Skills Demonstrated
- **Security Fundamentals:** Applying the CIA Triad (Confidentiality, Integrity, Availability), least-privilege access control, authentication, and cryptography
- **Threat & Vulnerability Awareness:** Identifying phishing/social engineering tactics, malware behavior, and common network or system vulnerabilities
- **Governance, Risk & Compliance (GRC):** Understanding security policies, data privacy protections (PII), incident response workflows, and regulatory compliance
